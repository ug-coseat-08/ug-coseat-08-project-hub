# Meeting Minutes

Meeting records are organised by type:

- `supervisor/` — weekly supervisor meetings.
- `group/` — weekly internal team meetings.
- `client/` — meetings with the client and other client-side stakeholders.

## Required format

Use the same concise format for every record:

1. Date, time, channel, and meeting type.
2. Every attendee by name and every absent member by name; write `None` when nobody is absent.
3. Agenda.
4. Important discussion and outcomes.
5. Decisions or agreements.
6. Actions with owners and deadlines.

Do not reproduce the conversation. Preserve the information needed to prove attendance, decisions, responsibilities, planned work, and follow-up. File each week's minutes in this repository by Sunday. The supervisor confirmed on 13 August 2026 that a complete GitHub record is sufficient and does not also need to be maintained in OneDrive.
